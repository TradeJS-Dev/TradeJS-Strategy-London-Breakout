# LondonBreakout

Плагин TradeJS по мотивам [«Лондонского взрыва» Empirix](https://empirix.ru/strategiya-london-session-optimizaciya-proshlaya-i-budushchaya-dohodnost/).

В 08:00 UTC стратегия фиксирует максимум и минимум девяти закрытых часовых свечей, начиная с 23:00 предыдущего дня. Если час пропущен или ширина диапазона больше половины дневного ATR, входы в этот день пропускаются. ATR Уайлдера за 14 периодов считается по полным дням UTC, собранным из H1. Для начального значения нужно 15 полных дней подряд, включая день для предыдущей цены закрытия.

Empirix выставляет две встречные стоп-заявки и отменяет вторую после первого исполнения. Здесь первый свежий переход закрытия H1 за уровень в окне с 08:00 до 16:00 UTC, исключая 16:00, даёт сигнал на рыночное исполнение TradeJS. В бэктесте плагин запрашивает открытие следующей доступной свечи на отметке подтверждения. Уровни ставятся на расстоянии 0,20 ATR за границами. Касание тенью и закрытие ровно на уровне не дают сигнал. Стратегия допускает одну попытку входа на инструмент за день. Окно входа и подтверждение закрытием H1 выбраны для криптовалютного прототипа.

Защита для предварительной проверки заявки считается от цены сигнала. Сразу после исполнения стратегия выставляет стоп на 0.5 ATR и тейк на 1.3 ATR от фактической цены позиции. Если следующая доступная цена перескочила предварительный стоп или тейк, штатное исполнение TradeJS может отклонить заявку. Открытая позиция закрывается по времени при закрытии H1 в 08:00 UTC следующего дня. Все часы фиксированы круглый год. При перезапуске сигналы восстанавливаются из истории закрытых H1. Если открытая позиция сохранилась, а срок её выхода потерян, стратегия запрашивает закрытие при ближайшем решении.

## Настройки по умолчанию

Новый исследовательский baseline открывает только шорты с обученным фильтром `LONDON_SHORT_GATE: "trained"`. Фильтр оценивает относительный объём сигнальной свечи, глубину пробоя, ширину диапазона, тело свечи и час подтверждения. Относительный объём считается по 20 предыдущим закрытым H1. При отсутствии данных или оценке ниже порога заявка пропускается. Такая попытка использует дневной лимит входа.

Коэффициенты зафиксированы по результатам обучения до 22 марта 2026 года, 12:00 UTC. В отложенной части двухлетнего прогона на 428 USDT-контрактах Bybit модель дала −1 421,93 USDT при просадке 3 953,45 USDT. Шорты без фильтра дали −1 237,01 USDT при просадке 6 981,48 USDT. Новый baseline принят для дальнейших исследований.

| Поле                             | По умолчанию | Назначение                                                        |
| -------------------------------- | -----------: | ----------------------------------------------------------------- |
| `LONDON_MAX_RANGE_ATR`           |          0.5 | Предельная ширина диапазона в ATR                                 |
| `LONDON_ENTRY_BUFFER_ATR`        |          0.2 | Отступ для подтверждения пробоя в ATR                             |
| `LONDON_SHORT_GATE`              |    `trained` | `off` отключает обученный фильтр шортов                           |
| `LONDON_SHORT_MAX_REL_VOLUME`    |            0 | Верхний предел относительного объёма. Ноль отключает проверку     |
| `LONDON_SHORT_MAX_OVERSHOOT_ATR` |            0 | Верхний предел глубины пробоя в ATR. Ноль отключает проверку      |
| `LONDON_STOP_ATR`                |          0.5 | Расстояние стопа в ATR                                            |
| `LONDON_TARGET_ATR`              |          1.3 | Расстояние тейка в ATR                                            |
| `LONDON_ENTRY_HOUR`              |            8 | Начало восьмичасового окна в UTC                                  |
| `LONDON_RANGE_MODE`              |      `fixed` | `rolling` берёт девять часов перед сигнальной свечой, исключая её |
| `MAX_LOSS_VALUE`                 |           10 | Бюджет риска для расчёта объёма                                   |
| `RISK_FEE_RATE`                  |      0.00055 | Оценка односторонней комиссии для расчёта объёма                  |
| `RISK_SLIPPAGE_BPS`              |            2 | Оценка проскальзывания для расчёта объёма                         |

График сделки показывает исходный диапазон, оба уровня входа и закрытие свечи, подтвердившей пробой.

Для локальной проверки выполните `yarn install` и `yarn checks` на Node.js 24. Собранный плагин экспортирует `strategyEntries` из `dist/index.js`. Для контроля из шортов без фильтров установите `LONDON_SHORT_GATE: "off"`. Для исходного варианта дополнительно установите `LONG.enable: true` и `LONDON_ENTRY_BUFFER_ATR: 0.1`. Для сравнения с другим окном установите `LONDON_ENTRY_HOUR: 0`. Для сравнения со скользящим диапазоном установите `LONDON_RANGE_MODE: "rolling"` и сохраните час 8.
